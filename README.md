# Wave

A 3D surfing game for the browser, built with Three.js. Walk out from the beach, paddle through the surf, duck under breaking waves, drop in and ride to shore.

## Controls

| Action | Touch | Keyboard |
|---|---|---|
| Go forward (walk / paddle) | Hold both hands | Left + Right arrow, or Up arrow |
| Turn | Hold one hand | Left or Right arrow |
| Drop in / duck / jump | Big middle button | Space |
| Duck dive | Big middle button | Down arrow |
| On the wave: climb / drop away | Left / right hand | Left / right arrow |
| Crouch for speed | Both hands | Left + Right arrow |
| Spin in the air | Hold a hand | Left / right arrow |

## Run locally

Open `index.html` in a browser. It loads Three.js (r128) from cdnjs, so you need an internet connection.

## Play online

Turn on GitHub Pages for this repo (Settings > Pages > Deploy from a branch > `main` / root).
